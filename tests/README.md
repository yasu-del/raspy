# CPU温度レコーダー 動作確認テストの解説

このディレクトリ内にある動作確認テスト用スクリプト [test_cpu_recorder.py] で使用されているクラスおよび関数の役割と処理内容についての解説です。

---

## 1. テスト対象：[recorder.py] 内の関数

* ### **[get_cpu_temp] 関数**
  * **説明**: ラズパイのCPU温度を取得するメインの関数です。
  * **動作**: 
    * **Linux環境（実際のラズパイ）**: 温度データが記録されるシステムファイル `/sys/class/thermal/thermal_zone0/temp` を読み込みます。ファイル内はミリ度単位（例: `45000`）で格納されているため、これを `1000.0` で割って摂氏温度（`45.0`度）に変換して返します。
    * **Windowsなどのテスト環境（ファイルが存在しない場合）**: エラーをキャッチして `42.0` 〜 `48.0` 度の間のランダムな数値をシミュレーション値として返します。

* ### **[main] 関数**
  * **説明**: スクリプトを直接実行した際のエントリポイントです。
  * **動作**: `get_cpu_temp` を5回（1秒おきに）呼び出し、コンソールに温度を表示するとともに、`sensor_log.txt` というファイルに日時とセットで記録します。

---

## 2. テスト側：[test_cpu_recorder.py] 内のクラスとメソッド

* ### **[TestCPURecorder] クラス**
  * **説明**: `unittest.TestCase` を継承した、テストケースをまとめるためのクラスです。

* ### **[setUp] メソッド**
  * **説明**: テストを実行する前の「準備処理」を行うメソッドです。
  * **動作**: テスト対象である `recorder.py` モジュールが正常にインポートされているかを確認します。もしインポートできていない場合は、以降のテストを自動的にスキップ（`skipTest`）します。

* ### **[test_get_cpu_temp_fallback] メソッド**
  * **説明**: Windowsなどの「ラズパイ以外の環境」で動かした際の、フォールバック（代わりの挙動）をテストします。
  * **動作**: `get_cpu_temp` を呼び出し、返ってきた値が正しく `float`（小数）型であること、および想定されるシミュレーション範囲（42.0度 〜 48.0度）に収まっているかをアサート（検証）します。

* ### **[test_get_cpu_temp_linux] メソッド**
  * **説明**: 「実際のラズパイ（Linux）環境」でシステム温度ファイルを読み込んだ場合の計算処理をモック化して検証します。
  * **動作**: Python の `unittest.mock.patch` デコレータを使い、組み込みの `open` 関数を一時的にダミー（モック）に差し替えます。このダミーファイルから `"45200"` という文字列を読み込ませることで、`get_cpu_temp` が計算を行って正しく `45.2`（度）に変換できるかを確認します。また、正しいファイルパス（`/sys/class/thermal/thermal_zone0/temp`）に対して読み込みが試行されたかも検証します。
